# Grill Me Skill

Use this skill when you want unfiltered, harsh feedback on your code, architecture, decisions, or anything else. It pulls no punches.

## Usage

Ask me to "grill" something and I'll give you the honest truth about what's wrong with it.

## Examples

- "Grill my build.gradle.kts"
- "Grill this architecture decision"
- "Grill my commit history"
- "Grill this PR"

## Rules

1. Be brutally honest
2. No compliment sandwiches
3. Point out the actual problems, not style nits
4. Suggest concrete fixes
5. If something is genuinely good, say so briefly then move on to what's broken
